# CareJH

하루 건강 기록 앱 — 수면, 식사, 운동, 음주, 물, 체중, 컨디션.

- 휴대폰 홈 화면에 추가해서 일반 앱처럼 쓰는 웹앱(PWA)입니다. 아이폰, 안드로이드 모두 됩니다.
- **기록은 각자 휴대폰 안에만 저장**되고 어디에도 전송되지 않아요. 서버도, 로그인도 없습니다.
- 인터넷이 없어도 열리고 기록할 수 있어요 (처음 한 번은 인터넷이 필요).

## 기능

| 탭 | 내용 |
|---|---|
| 기록 | 오늘(또는 지난 날) 기록. 버튼 몇 번이면 끝. 좌우로 밀면 날짜 이동 |
| 캘린더 | 한 달 동안 무엇을 기록했는지 점으로 표시, 날짜를 누르면 그날 요약 |
| 통계 | 주간 / 월간 / 3개월 요약, 지난 기간 대비 변화, 차트, 패턴 찾기 |
| 설정 | 이름, 목표(수면·물·운동·음주), 기록할 항목 켜고 끄기, 테마, 백업 |

- 수면: 잠든 시간 → 일어난 시간 (그날 **아침에 일어난 날짜**에 기록), 개운함
- 식사: 아침·점심·저녁·간식/야식마다 건강 / 보통 / 과식 / 안 먹음
- 운동: 종류, 시간, 강도. 여러 번 추가 가능. 주간 목표 대비 진행률
- 음주: 소주·맥주·소맥·와인·막걸리·위스키·하이볼을 잔 단위로. 알코올 g과 "소주 몇 잔 분량"으로 환산
- 새벽 4시 전까지는 전날로 기록돼요 (늦은 술자리, 야식용)

## 휴대폰에 설치하기

앱을 HTTPS 주소로 올려야 휴대폰에서 설치할 수 있어요. 무료로 가장 쉬운 방법은 GitHub Pages입니다.

### 1. GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만들어요 (예: `CareJH`).
2. 이 폴더의 파일을 그대로 올려요.
   ```bash
   git init && git add . && git commit -m "CareJH"
   git branch -M main
   git remote add origin https://github.com/<아이디>/CareJH.git
   git push -u origin main
   ```
3. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/(root)`로 저장해요.
4. 1~2분 뒤 `https://<아이디>.github.io/CareJH/` 에서 열려요.

> 무료 계정이면 저장소(코드)는 공개되지만, 건강 기록은 각자 폰에만 있으니 공개되지 않아요.

### 2. 홈 화면에 추가

- **아이폰**: Safari로 주소를 열고 → 아래쪽 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 열고 → 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 **앱 설치**)

⚠️ 아이폰은 Safari 탭과 홈 화면 앱의 저장 공간이 따로예요. **홈 화면에 추가한 뒤 그 아이콘으로 열어서** 기록해 주세요.

## 백업

기록이 폰 안에만 있으니, 폰을 바꾸거나 앱(홈 화면 아이콘)을 지우면 기록도 사라져요.

- 설정 → **백업 파일 만들기**: JSON 파일을 저장하거나 카톡·메일·파일 앱으로 보낼 수 있어요.
- 설정 → **백업 파일 불러오기**: 새 폰에서 불러오면 기록이 돌아와요. 같은 날짜는 백업 내용으로 바뀌고 나머지는 그대로예요.
- 기록이 2주 넘게 쌓이면 한 달에 한 번 백업하라고 알려 줘요.

## 고쳐서 쓰기

빌드 과정 없는 순수 HTML/CSS/JS라서 파일을 고치고 다시 올리면 끝이에요.

```bash
python3 dev-server.py
```

http://localhost:8765 에서 확인할 수 있어요 (개발 중엔 오프라인 캐시가 꺼져 있어요).

| 파일 | 역할 |
|---|---|
| `js/constants.js` | 운동 종류, 술 종류와 알코올 양, 식사·기분 단계 |
| `js/store.js` | 저장(localStorage), 백업 |
| `js/metrics.js` | 수면 시간·알코올 계산, 요약 문구 |
| `js/views/*.js` | 화면 4개 (기록, 캘린더, 통계, 설정) |
| `js/charts.js` | SVG 차트 |
| `css/app.css` | 디자인, 라이트/다크 색상 |
| `sw.js` | 오프라인 캐시 |

- 올린 뒤 휴대폰에서는 **앱을 두 번 열면** 새 버전이 보여요.
- 새 파일을 추가했다면 `sw.js`의 `ASSETS` 목록에도 넣고, `CACHE` 이름(`carejh-v1` → `v2`)을 올려 주세요.
